# Release Notes

## v2.0.0

### Исправления

* Таблица билета: убрана ссылка на несуществующую строку (`row{2-4}` в режиме 2 вопросов)
* Переменное число вопросов в билете: цикл `expl3` по столбцам, пустая ячейка CSV пропускается (`"Вопрос 1","Вопрос 2",` → 2 вопроса). Полностью заполненный CSV работает как раньше
* Формулы в вопросах: встроенная математика `\(x^2=4\)`
* Изображения в вопросах: `\protect\includegraphics{case1.png}`, файлы — в каталоге `images/`
* Переносы строк в вопросах: `\\` (авто-перенос по ширине колонки сохраняется)
* Валидация конфигурации на этапе компиляции: число столбцов CSV ↔ `\NumberOfQuestions` и диапазон 1–3, понятная ошибка при рассинхроне
* Устранено дублирование блока `tblr` — единый блок, строки билета собираются динамически и разворачиваются через ключ `tabularray` `expand`
* Настройки разнесены: `config.tex` (общие) + `course.tex` (дисциплина); `main.tex` — оркестратор
* Сборка через `Makefile` + `latexmk` (`make build` / `clean` / `distclean`) — авто-мультипроход
* CI переведён на `xu-cheng/latex-action` (TeXLive-образ вместо ручной установки пакетов)
* CI автоматически коммитит обновлённый `exam_cards.pdf` обратно в репозиторий (на `push`)
